# Motion Atlas Assets

Web-optimized SVG assets for the Motion Atlas visual system.

- `backgrounds/animated-gradient.svg` - animated dark neon gradient field.
- `shapes/glass-shapes.svg` - abstract floating glass 3D-style objects.
- `overlays/glow-particles.svg` - animated glow particles and light trails.
- `thumbnails/*.svg` - UI preview thumbnails for motion showcase cards.

These assets are vector-based and include lightweight SVG animation. Respect
`prefers-reduced-motion` from the consuming UI when deciding whether to render
animated versions.
